# BookStore

Nền tảng bookstore theo định hướng **Cozy Bookstore**. Repository chính thức: https://github.com/Tran-Nhat-Duy1206/BookStore.

## Trạng thái

Milestone được duyệt: Frontend Foundation với Next.js App Router, React, TypeScript, Tailwind CSS, Motion và fixture minh họa. Modular monolith; PostgreSQL/Prisma dành cho backend tương lai.

Chưa có cửa hàng vật lý, địa chỉ hoặc tồn kho được xác nhận. Không nhận đơn, thanh toán, đăng nhập khách hàng hoặc giao hàng thật. Không deploy hoặc sử dụng dịch vụ trả phí trong milestone này.

## Quy trình

`main` là nền tảng ban đầu; triển khai trên `feat/bookstore-foundation` và review qua Draft PR. Không merge nếu chưa được phê duyệt.

Tài liệu và hướng dẫn phát triển sẽ được bổ sung trên feature branch.
